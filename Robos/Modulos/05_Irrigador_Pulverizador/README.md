# Módulo 05 — Irrigador Cirúrgico e Pulverizador Micro-Localizado

## 1. Visão Geral
Aplicação de precisão (See-and-Spray) de bioinsumos e irrigação cirúrgica gota-a-gota.

## 2. Especificações Técnicas
- **Tanque**: 60 Litros PEAD rotomoldado anti-balanço
- **Pressurização**: Bomba Diafragma Seaflo 24V 100 PSI (5,5 L/min)
- **Barra de Pulverização**: 3 bicos cerâmicos c/ Eletroválvulas Solenoides Rápidas Inox (8 ms)

## 3. Arquitetura ROS 2
Disparo milissegundado sincronizado com detecção de pragas pela câmera OAK-D.
